Hydroponics Monitoring

An ESP32-S3 controller redesign for a seven-sensor hydroponics monitoring system.

I designed and tested the sensor interfaces, including the circuits that scale and filter analog voltages for the ADC. I also built a 3S LiPo backup supply to keep essential monitoring running when external power drops out.

I lead the two-layer PCB design and review the team’s C/FreeRTOS firmware, which uses BLE and MQTT.

Follow an analog reading

Sensor output

An analog sensor produces a voltage that varies with the physical quantity it measures.

Scale and filter

The interface scales the voltage to the ADC input range and filters unwanted variation before sampling.

Sample on the ESP32-S3

The analog-to-digital converter (ADC) turns the conditioned voltage into a number the firmware can read.

Process in firmware

The C/FreeRTOS firmware handles sensor readings. The monitoring system uses BLE and MQTT to exchange data.

Project LeadDec 2025 – Jun 2026

DropLock

A Raspberry Pi parcel locker built for the full handoff from online booking to verified pickup.

I led a five-person team and developed tablet session control, a Streamlit/Firebase dashboard, and a FastAPI booking API. The prototype brought QR access, MQTT, door and tamper sensing, and HX711 weight verification together.

University Best Project Award

From booking to pickup

Book a delivery

The booking website connects to the FastAPI service to create a locker booking.

Scan for access

A QR code is presented at the locker. The tablet handles the session at the prototype.

Check door state and weight

Door and tamper sensors report the locker state. A load cell read through the HX711 supplies the weight measurement.

Verify pickup

The recipient uses QR access to collect the parcel. Weight sensing gives the system a way to check that the parcel was removed.

Project LeadSep 2025 – Dec 2025

HomeGuard

An indoor monitoring rover that measures its surroundings and steers around obstacles.

I wrote C firmware for the STM32F439 to drive the stepper motors, detect obstacles with ultrasonic sensors, and collect BME280 and MQ-2 readings.

I implemented timer interrupts, PWM, ADC and I²C, and sent telemetry through an ESP8266. I worked on both bare-metal and FreeRTOS versions of the firmware.

AuthorSep 2025

STM-Open-Library

Five reusable peripheral drivers for STM32 microcontrollers.

I wrote these modules using STM32’s hardware abstraction layer (HAL). Each driver comes with wiring notes, setup instructions, and a C example that shows how to use it.

Open GitHub repository
